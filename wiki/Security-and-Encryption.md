# 🔒 Security & Encryption

Keamanan dan privasi data adalah pilar fundamental dari platform **phone-backup**. Seluruh data dan metadata diamankan menggunakan standar kriptografi modern berstandar industri.

---

## 1. Model Keamanan Zero-Knowledge

Dalam model **Zero-Knowledge Storage**, data dienkripsi secara lokal di perangkat Anda sebelum disimpan ke disk atau dikirim ke cloud. Penyedia cloud atau pihak ketiga mana pun hanya melihat *ciphertext* yang tidak dapat dibaca tanpa kunci otorisasi.

---

## 2. Enkripsi Simetris (AES-256-GCM + Argon2id)

### A. Derivasi Kunci Master (Argon2id KDF)
Kata sandi pengguna tidak pernah disimpan dalam bentuk teks biasa. Fungsi `EncryptionEngine::derive_database_key` menggunakan algoritma **Argon2id** (tahan terhadap serangan brute-force GPU/ASIC) dengan parameter:
- **Panjang Kunci**: 256-bit (32 bytes / 64-karakter Hex).
- **Salt Kriptografis**: Salt unik untuk setiap instance database.

### B. Enkripsi Objek (AES-256-GCM)
Setiap blok dan berkas terenkripsi menggunakan **AES-256-GCM** (*Galois/Counter Mode*), yang memberikan:
- **Kerahasiaan (Confidentiality)**: Mencegah akses tidak sah ke isi file.
- **Integritas & Otentikasi (Authenticated Encryption)**: Authentication Tag 128-bit memastikan data tidak dapat diubah atau dirusak secara diam-diam (*anti-tampering*).

---

## 3. Enkripsi Asimetris (age X25519)

Untuk skenario backup otomatis tanpa menyimpan sandi di komputer backup, sistem mendukung format standar **age (Actually Good Encryption)**:

1. **Kunci Publik (`age1...`)**: Digunakan oleh daemon backup untuk mengunci payload data secara satu arah.
2. **Kunci Privat (`AGE-SECRET-KEY-1...`)**: Disimpan secara aman dan terpisah oleh pengguna (offline). Hanya dibutuhkan saat melakukan pemulihan (*restore*).

```bash
# Membuat pasangan kunci
phone-backup keygen

# Mengunci backup dengan kunci publik
phone-backup --adapter adb backup --pubkey "age1..." <DEVICE_ID>

# Memulihkan backup dengan kunci privat
phone-backup --privkey "AGE-SECRET-KEY-1..." restore <SNAPSHOT_ID>
```

---

## 4. Enkripsi Database Metadata (SQLCipher)

Database metadata `backup.db` berisi riwayat snapshot, relasi berkas, dan buku telepon kontak yang sangat sensitif.
- **SQLCipher AES-256**: Mengenkripsi seluruh halaman database SQLite pada level disk I/O.
- **Pool Connection Customization**: Saat r2d2 connection pool membuat koneksi baru, `SqliteCustomizer` secara otomatis mengeksekusi `PRAGMA key = '<hex_key>';` untuk membuka akses database secara transparan dan aman.

---

## 5. Tauri ACL & Capabilities Security

Pada lapisan Desktop GUI, seluruh IPC command Tauri dibatasi oleh **Tauri Access Control List (ACL)**:
- Berkas izin `permissions/autogenerated.toml` dan `acl-manifests.json` membatasi akses endpoint hardware (`download_from_device`, `calculate_device_file_hash`, dll.).
- Mencegah injeksi eksekusi berbahaya dari antarmuka web ke sistem operasi host.
